Welcome to FFT Sync

  1. Click Add Pictures Folder and pick where the FFT folder should be created (for example Documents). Allow the permission when the browser asks.
  2. Files from the cloud download into that folder. Anything you add, edit or delete there syncs automatically every few seconds.
  3. Keep this page open while you work. Click Refresh to sync right away.
  4. After reloading the page, click anywhere once to reconnect. Choose Allow on every visit in the prompt to skip this step.
  5. Use desktop Chrome or Edge.
